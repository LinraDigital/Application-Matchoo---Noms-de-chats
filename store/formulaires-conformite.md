# Réponses aux formulaires de conformité

## Google Play – Sécurité des données
- Collecte de données : **Oui** (par le SDK publicitaire uniquement)
- Données partagées : **Identifiants d'appareil ou autres (ID publicitaire)** → partagées avec Google AdMob, finalité « Publicité ou marketing », collecte facultative : non (liée aux pubs)
- Données approximatives : adresse IP / localisation approximative traitées par AdMob (finalité publicité)
- Données de l'appli (favoris, filtres) : stockées **uniquement sur l'appareil**, jamais envoyées
- Chiffrement en transit : oui · Suppression des données : pas de compte, désinstaller l'appli suffit
- Appli destinée aux enfants : **non** (public tout âge, pas ciblée sur les moins de 13 ans)
- Annonces : **oui, contient des annonces**
- Appli : gratuite · Classification du contenu (questionnaire IARC) : aucun contenu sensible → tout public

## Apple – App Privacy (étiquettes)
- Données utilisées pour vous suivre : **Identifiants (IDFA)** — via AdMob, avec la fenêtre ATT
- Données non liées à l'utilisateur : Données d'utilisation / Diagnostics (AdMob)
- Chiffrement : oui · Tranche d'âge : 4+ · Export / chiffrement : exempté (HTTPS standard)
- Texte ATT déjà configuré : « Cet identifiant sert à afficher des publicités plus pertinentes. Vous pouvez refuser. »

## Consentement RGPD
Message de consentement (UMP) à configurer dans AdMob → Confidentialité et messagerie (déjà fait pour l'appli chiens : à refaire pour ce nouvel identifiant d'appli).
